# 订单搜索前端页面

## 功能特性

### ✨ 核心功能
- 🔍 **快速搜索**：支持订单号、手机号、姓名、地址关键词搜索
- 🎯 **高级筛选**：时间范围、订单状态、产品类型、金额范围
- 📊 **实时统计**：显示搜索结果数量和查询耗时
- 📱 **响应式设计**：完美适配PC和移动端
- 🎨 **现代UI**：渐变色设计，流畅动画效果

### 🎯 搜索功能

#### 1. 快速搜索
- 订单号精确查询（如：SF202510300001）
- 手机号模糊查询（支持脱敏格式：138****8000）
- 姓名全文检索（如：张三）
- 地址关键词搜索（如：北京市朝阳区）

#### 2. 高级筛选
- **时间范围**：选择开始和结束日期
- **订单状态**：待揽收、运输中、已签收（支持多选）
- **产品类型**：文件、包裹、生鲜
- **金额范围**：设置最小和最大金额

### 📋 显示信息

每个订单卡片显示：
- 订单号
- 订单状态（带颜色标识）
- 寄件人信息（姓名、电话 - 已脱敏）
- 收件人信息（姓名、电话 - 已脱敏）
- 寄件地址
- 收件地址
- 订单金额
- 创建时间

### 🎨 UI特性

- **渐变背景**：紫色渐变背景，视觉效果出众
- **卡片设计**：白色卡片，圆角阴影
- **状态标签**：不同状态用不同颜色区分
  - 已签收：绿色
  - 待揽收：橙色
  - 运输中：蓝色
- **悬停效果**：鼠标悬停时卡片高亮
- **加载动画**：搜索时显示加载状态
- **空状态**：无结果时显示友好提示

## 使用方法

### 1. 启动后端服务

```bash
cd server/ShunFengParcel/ShunFengParcel
./bin/server.exe -conf ./configs
```

### 2. 打开前端页面

直接在浏览器中打开 `web/order-search.html`

或者使用本地服务器：

```bash
# 使用Python
cd web
python -m http.server 8080

# 使用Node.js
npx http-server -p 8080

# 使用VS Code Live Server插件
# 右键点击 order-search.html -> Open with Live Server
```

### 3. 开始搜索

1. **快速搜索**：
   - 在搜索框输入关键词
   - 点击"搜索"按钮或按回车键

2. **高级筛选**：
   - 展开高级筛选区域
   - 设置筛选条件
   - 点击"应用筛选"按钮

3. **查看结果**：
   - 浏览搜索结果列表
   - 使用分页浏览更多结果

4. **重置筛选**：
   - 点击"重置"按钮清空所有条件

## 配置说明

### API地址配置

在 `order-search.html` 中修改API地址：

```javascript
const API_BASE_URL = 'http://localhost:18000';
```

如果后端部署在其他地址，修改为实际地址即可。

### 分页配置

默认每页显示10条记录，可在代码中修改：

```javascript
const requestBody = {
    // ...
    page_size: 10  // 修改这里
};
```

## 常见问题

### Q1: 搜索无结果？

**A:** 检查以下几点：
1. 后端服务是否正常运行
2. ES索引是否已创建并同步数据
3. 搜索条件是否过于严格
4. 查看浏览器控制台是否有错误

### Q2: 显示CORS错误？

**A:** 后端已配置CORS，如果仍有问题：
1. 检查后端CORS配置
2. 使用浏览器插件临时禁用CORS
3. 使用本地服务器运行前端

### Q3: 数据显示不完整？

**A:** 可能原因：
1. 后端返回数据格式不匹配
2. 某些字段为空
3. 查看浏览器控制台日志

### Q4: 分页不显示？

**A:** 当总结果少于10条时不显示分页，这是正常的。

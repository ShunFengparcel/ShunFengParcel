# 快速开始 - 查看项目效果

## 🚀 最快的方式：使用 HBuilderX

### 步骤 1：下载 HBuilderX
1. 访问：https://www.dcloud.io/hbuilderx.html
2. 下载 **HBuilderX 标准版**（约 200MB）
3. 解压后直接运行，无需安装

### 步骤 2：导入项目
1. 打开 HBuilderX
2. 点击菜单：**文件** -> **导入** -> **从本地目录导入**
3. 选择项目目录：`D:\gowork\src\ShunFengParcel\web\user-client`
4. 点击 **选择文件夹**

### 步骤 3：运行项目
1. 在 HBuilderX 中，点击顶部菜单：**运行** -> **运行到小程序模拟器** -> **微信开发者工具**
2. 首次运行会提示配置微信开发者工具路径
3. 如果没有微信开发者工具，会提示下载

### 步骤 4：查看效果
- 微信开发者工具会自动打开
- 可以看到小程序运行效果
- 可以点击不同的 Tab 查看各个页面

## 📱 方法二：使用微信开发者工具

### 步骤 1：下载微信开发者工具
1. 访问：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载并安装微信开发者工具

### 步骤 2：编译项目
在项目目录下运行：
```bash
cd D:\gowork\src\ShunFengParcel\web\user-client
npm install
npm run dev:mp-weixin
```

### 步骤 3：导入到微信开发者工具
1. 打开微信开发者工具
2. 点击 **+** 号，选择 **导入项目**
3. 项目目录选择：`D:\gowork\src\ShunFengParcel\web\user-client\dist\dev\mp-weixin`
4. AppID 选择：**测试号**（或使用自己的 AppID）
5. 点击 **导入**

### 步骤 4：查看效果
- 在微信开发者工具中可以看到小程序运行效果
- 左侧是模拟器，右侧是代码编辑器
- 可以点击不同的 Tab 查看各个页面

## 🔧 如果遇到问题

### 问题 1：HBuilderX 找不到微信开发者工具
**解决方案：**
1. 先安装微信开发者工具
2. 在 HBuilderX 中：**工具** -> **设置** -> **运行配置**
3. 配置微信开发者工具的安装路径

### 问题 2：npm install 失败
**解决方案：**
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com

# 或使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

### 问题 3：页面显示空白
**解决方案：**
1. 检查是否正确导入项目
2. 检查微信开发者工具是否选择了正确的目录
3. 尝试重新编译：`npm run dev:mp-weixin`

### 问题 4：提示缺少 AppID
**解决方案：**
1. 在微信开发者工具中选择 **测试号**
2. 或在 `manifest.json` 中配置自己的 AppID

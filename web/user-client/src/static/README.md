# 静态资源说明

## TabBar 图标

需要准备以下 TabBar 图标（建议尺寸：81x81px）：

### 首页
- `tabbar/home.png` - 首页未选中图标
- `tabbar/home-active.png` - 首页选中图标（红色）

### 查快递
- `tabbar/search.png` - 查快递未选中图标
- `tabbar/search-active.png` - 查快递选中图标（红色）

### 寄快递
- `tabbar/send.png` - 寄快递未选中图标
- `tabbar/send-active.png` - 寄快递选中图标（红色）

### 我的
- `tabbar/user.png` - 我的未选中图标
- `tabbar/user-active.png` - 我的选中图标（红色）

## 其他图标

### 用户头像
- `images/default-avatar.png` - 默认用户头像

### 空状态图片
- `images/empty-box.png` - 空包裹图标
- `images/empty-order.png` - 空订单图标

## 图标获取方式

1. 从 iconfont 下载图标
2. 使用 Figma/Sketch 设计
3. 从原型图中提取

## 颜色规范

- 主色（顺丰红）：#D81E06
- 未选中图标：#7A7E83
- 选中图标：#D81E06

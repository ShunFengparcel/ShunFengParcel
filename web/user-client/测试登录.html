🚀 微信登录测试指南

⚠️ 注意：这个HTML文件只是指导文档，不能直接运行登录功能。请在微信开发者工具中操作。

方法1：在微信开发者工具的Console中执行

1. 打开微信开发者工具

2. 点击底部的 Console 标签（控制台）

3. 在控制台输入以下代码并按回车：

wx.navigateTo({url: '/pages/login/login'})

方法2：修改首页跳转

1. 在首页点击任意功能按钮（如"快速寄件"）

2. 如果未登录，应该会自动跳转到登录页

方法3：直接修改URL（推荐）

1. 在微信开发者工具顶部找到地址栏

2. 清空当前内容

3. 输入：pages/login/login

4. 按回车键

✅ 登录成功的标志

  • 前端显示"登录成功"提示
  • 自动跳转到首页
  • 后端控制台显示：
    ⚠️ 测试模式：使用模拟openid: test_openid_xxx
    📝 查询用户: openid=test_openid_xxx
    ✅ 创建新用户成功: ID=1, Nickname=测试用户
    🎉 登录成功: UserID=1, Token=eyJhbGciOiJIUzI1NiIs...

🔍 如果还是找不到登录页面

可以尝试以下操作：

  1. 重新编译前端项目
  2. 清除微信开发者工具的所有缓存
  3. 重启微信开发者工具
  4. 检查 pages.json 中是否有 pages/login/login 配置

📝 后续步骤

登录成功后

1. 查看数据库中是否有新用户记录：

SELECT * FROM sf_users ORDER BY created_at DESC LIMIT 1;

2. 关联订单数据（选择一种方法）：

-- 方法A：创建新订单（在小程序中操作）
点击"寄快递" → 填写信息 → 提交

-- 方法B：关联现有订单
UPDATE sf_orders SET user_id = (SELECT id FROM sf_users ORDER BY created_at DESC LIMIT 1) WHERE id IN (1,2,3);

3. 测试订单查询：

在小程序中点击"查快递"，应该能看到订单列表

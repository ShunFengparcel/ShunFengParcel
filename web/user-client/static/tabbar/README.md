# TabBar图标说明

## 临时解决方案

由于TabBar图标文件缺失，我们暂时移除了图标配置，只使用文字标签。

## 如需添加图标

请准备以下尺寸的图标文件（PNG格式）：
- 尺寸: 81px * 81px
- 格式: PNG
- 背景: 透明

### 需要的图标文件

1. home.png - 首页图标（未选中）
2. home-active.png - 首页图标（选中，红色）
3. search.png - 查快递图标（未选中）
4. search-active.png - 查快递图标（选中，红色）
5. send.png - 寄快递图标（未选中）
6. send-active.png - 寄快递图标（选中，红色）
7. user.png - 我的图标（未选中）
8. user-active.png - 我的图标（选中，红色）

### 颜色规范
- 未选中: #7A7E83 (灰色)
- 选中: #D81E06 (顺丰红)

## 技术实现

### 状态管理
- 使用 Pinia 管理全局状态
- User Store：用户信息、登录状态、地址列表
- Order Store：订单列表、当前订单、物流信息

### API 封装
- 统一的请求拦截器（添加 Token）
- 统一的响应拦截器（错误处理）
- 支持请求重试机制

### 路由拦截
- 登录验证
- 需要登录的页面自动跳转到登录页

### 组件库
- Loading 加载组件
- Empty 空状态组件
- Toast 提示工具

## 运行项目

### 安装依赖
```bash
cd web/user-client
npm install
```

### 开发模式
```bash
npm run dev:mp-weixin
```

### 构建生产版本
```bash
npm run build:mp-weixin
```

### 使用微信开发者工具
1. 打开微信开发者工具
2. 导入项目，选择 `web/user-client/dist/dev/mp-weixin` 目录
3. 配置 AppID（在 manifest.json 中）

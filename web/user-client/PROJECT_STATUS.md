## 技术栈

- **框架**: uni-app 3.x + Vue 3
- **状态管理**: Pinia
- **构建工具**: Vite
- **代码规范**: ESLint + Prettier

## 项目结构

```
web/user-client/
├── components/          # 公共组件
│   ├── sf-loading/     # 加载组件
│   └── sf-empty/       # 空状态组件
├── pages/              # 页面文件
│   ├── index/         # 首页 ✅
│   ├── order/         # 查快递
│   ├── send/          # 寄快递
│   └── profile/       # 我的
├── stores/            # 状态管理
│   ├── user.js       # 用户状态 ✅
│   └── order.js      # 订单状态 ✅
├── utils/            # 工具函数
│   ├── request.js    # API 请求封装 ✅
│   ├── router.js     # 路由拦截 ✅
│   └── toast.js      # Toast 提示 ✅
└── static/           # 静态资源
```

## 如何运行

### 1. 安装依赖
```bash
cd web/user-client
npm install
```

### 2. 开发模式
```bash
npm run dev:mp-weixin
```

### 3. 使用微信开发者工具
1. 打开微信开发者工具
2. 导入项目，选择 `web/user-client/dist/dev/mp-weixin` 目录
3. 配置 AppID（在 manifest.json 中）

🧪 订单搜索API测试工具

测试用例

1. 基础搜索

测试不带任何条件的搜索，返回所有订单

{
  "page": 1,
  "page_size": 10
}

2. 订单号精确查询

通过订单号精确查询，性能要求 <50ms

{
  "keyword": "SF202510300001",
  "page": 1,
  "page_size": 10
}

3. 手机号模糊查询

通过手机号查询，性能要求 <200ms

{
  "keyword": "138****8000",
  "page": 1,
  "page_size": 10
}

4. 姓名全文检索

通过姓名查询，性能要求 <300ms

{
  "keyword": "张三",
  "page": 1,
  "page_size": 10
}

5. 地址全文检索

通过地址关键词查询

{
  "keyword": "北京市朝阳区",
  "page": 1,
  "page_size": 10
}

6. 时间范围查询

查询指定时间范围内的订单

{
  "start_date": "2025-10-01",
  "end_date": "2025-10-30",
  "page": 1,
  "page_size": 10
}

7. 订单状态筛选

查询特定状态的订单

{
  "status": ["SIGNED"],
  "page": 1,
  "page_size": 10
}

8. 多条件组合查询

组合多个查询条件，性能要求 <500ms

{
  "keyword": "张三",
  "start_date": "2025-10-01",
  "end_date": "2025-10-30",
  "status": ["SIGNED"],
  "product_type": "文件",
  "min_amount": 50,
  "max_amount": 100,
  "page": 1,
  "page_size": 20
}
